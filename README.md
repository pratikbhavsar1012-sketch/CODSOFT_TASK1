# CODSOFT Web Development — Level 1, Task 1: Portfolio

Responsive personal portfolio built with HTML, CSS, and JavaScript, covering the requirements in the supplied CodSoft PDF: header, about, skills, projects, resume link, contact information, and footer.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Update `your.email@example.com` and your LinkedIn URL in `index.html`.
4. Add your actual resume PDF in `resume/` named `Pratik_Bhavsar_Resume.pdf`.
5. Verify the project descriptions and repository links before publishing.

## Publish
This is a static site with no build step. You can deploy it with GitHub Pages or Netlify.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `resume/` — add your PDF resume here
- `assets/` — optional images
